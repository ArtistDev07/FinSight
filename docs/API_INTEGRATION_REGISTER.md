# FinSight — Phase 1 Complete Codebase & External API Integration Register

**Audit Scope:** Full-stack inspection of `package.json`, `server.ts`, `src/`, `firebase-applet-config.json`, `firestore.rules`, `.env.example`, and runtime environment.

---

## 1. External API & Infrastructure Inventory

| Service / Integration | Current State at Phase 1 Start | Target Integration & Resolution | Credentials / Env Vars Required |
| :--- | :--- | :--- | :--- |
| **Firebase Authentication** (`firebase/auth` + `firebase-admin/auth`) | **Connected & Functional** — Google Sign-In, Email/Password, token verification, session revocation active. | Preserve and wire token-authenticated access across all newly added APIs and preference endpoints. | `firebase-applet-config.json` (client config); `FIREBASE_PROJECT_ID` (optional server override) |
| **Cloud Firestore** (`firebase/firestore` + `firestore.rules`) | **Partially Implemented** — `firestore.rules` deployed and client SDK initialized, but `server.ts` stores data only in transient JS memory and rules omit newer collections (`watchlists`, `taxCalculations`, `taxDocuments`, `aiConversations`, etc.). Runtime probe confirms GCP ADC is not attached to this container (`PERMISSION_DENIED`). | Expand `firestore.rules` + `firebase-blueprint.json` to all 28 collections and deploy; build file-backed persistent server store (`.finsight-data/store.json`) with optional Firestore Admin write-through when ADC is present, plus explicit `/api/v1/health` status reporting. | GCP Application Default Credentials (`GOOGLE_APPLICATION_CREDENTIALS` if running outside Cloud Run with IAM permissions) |
| **Firebase Storage / Document Vault** | **Missing** — `storageBucket` exists in `firebase-applet-config.json`, but `storage.rules` is absent and `TaxModule`/`BudgetingModule` show fake client-only upload messages. | Add `storage.rules` enforcing owner isolation, MIME allowlist, and 10MB cap; implement server-side secure vault + real upload/download/delete endpoints for Tax Documents, Statements, Invoice PDFs, and Expense Receipts. | `storageBucket` (`firebase-applet-config.json`); ADC for bucket write-through if deployed with IAM |
| **Google Gemini API** (`@google/genai` v2.32.0) | **Incorrect Implementation** — `server.ts` uses unsupported model `'gemini-3.8-flash'`, lacks structured schema, lacks retry/timeout/rate-limiting, silently fakes success on error, and lacks conversation persistence or module-specific data grounding. | Switch to verified model `'gemini-4-hydrogen'`, add `responseSchema` for Fraud analysis, retry/backoff + 20s timeout + rate limiting + usage telemetry, conversation persistence, and grounded user-context module AI insights; surface errors honestly instead of faking AI replies. | `GEMINI_API_KEY` (server-side secret; runtime probe shows currently unset in container env) |
| **Market Data API (NSE Historical / Live)** | **Partially Implemented** — `server.ts` has 5 static summary quotes only; no OHLCV candles, no `/api/v1/markets/history`, no `/api/v1/watchlist`, and naive math in `/api/v1/backtests`. | Add curated verified NSE OHLCV historical dataset (`VERIFIED_NSE_ARCHIVE`), optional `MARKET_DATA_API_KEY` live/provider adapter with honest `/api/v1/health` status, real candle-driven strategy backtester, user watchlist CRUD, and isolated paper trading. | `MARKET_DATA_API_KEY` (optional external provider key; currently unconfigured, archived NSE dataset used transparently) |
| **Indian Income Tax Engine (CBDT Rules)** | **Partially Implemented** — Deterministic `calculateIndianTax` covers FY 2025-26 slabs, but lacks surcharge, FY 2024-25 versioning, saved calculation history, `/api/v1/tax/profile`, `/api/v1/tax/compare`, `/api/v1/tax/calculate`, and real document vault. | Add versioned CBDT rulesets (`FY 2025-26`, `FY 2024-25`), surcharge tiers, persisted calculation history, profile endpoints, deduction delete, and real tax document upload/download/delete. | None (verified statutory ruleset stored server-side) |
| **Bank Statement & SMS Parsing** | **Partially Implemented / Broken UI** — `BudgetingModule` CSV upload shows fake hardcoded `"12 transactions parsed"`; no XLSX/PDF/CSV parser or preview/import history endpoints exist. | Implement real CSV (`csv-parse`), XLSX (`xlsx`), PDF (`unpdf`), plain-text, and bank SMS parsing with duplicate detection, preview staging, batch import, and import job history. | None (server-side processing; no bank credential scraping) |
| **Small Business GST & PDF Invoicing** | **Partially Implemented** — Basic GST invoice CRUD exists, but `BusinessModule` cash-flow tab is hardcoded, expenses tab lacks creation/receipt UI, GST rate is hardcoded at 18%, GSTIN isn't validated, and PDF relies only on `window.print()`. | Add GSTIN format validation, configurable GST rates, multi-line support, real binary PDF download (`pdfkit`), expense creation & receipt vault, dynamic cash-flow forecasting, and client update/delete. | None |
| **Unnecessary External APIs (Verified Local)** | Live Broker Execution APIs, Account Aggregator / NetBanking Credential Scraping, Real Payment Gateways. | **Intentionally Excluded** — FinSight is an educational, advisory, and paper-simulation platform and must never execute real-money trades or collect banking passwords/PINs/OTPs. | N/A |

## 2. Frontend Hardcoded / Placeholder Findings Identified for Cleanup

1. `src/pages/dashboard/DashboardPage.tsx`: Fallback literals (`|| 180000`, `|| 55050`, `|| 124950`, `|| 855440`, `|| 92440`), hardcoded Cash Flow bars, hardcoded Spending Breakdown list, static Insights cards, and `Gemini 3.8` badge.
2. `src/pages/budgeting/BudgetingModule.tsx`: Hardcoded overview KPIs (`₹1,80,000`, `₹55,050`, `₹32,950`, `69.4%`), fake CSV `"12 transactions parsed"` status, missing Create/Delete Budget UI, and static Spending Insights cards.
3. `src/pages/markets/MarketsModule.tsx`: Non-zero hardcoded `paperAccount` initial state (`785400` / `242000`), missing user watchlist persistence, missing OHLCV chart & instrument detail view.
4. `src/pages/investments/InvestmentsModule.tsx`: Hardcoded `"Valuation as of 10 Mar 2026"` and missing empty state / portfolio selector.
5. `src/pages/tax/TaxModule.tsx`: Fake document upload status string, missing uploaded document list/download/delete, missing calculation save & history.
6. `src/pages/business/BusinessModule.tsx`: Hardcoded Cash Flow forecast numbers (`₹3,45,000`, `+₹1,41,600`, `-₹22,200`, `₹4,64,400`), missing Add Business Expense UI + receipt upload, missing real downloadable PDF button, and missing client/invoice delete controls.
7. `src/components/ai/GlobalAIAssistant.tsx`: Lacks persistent history load, clear conversation, copy message, retry failed prompt, and honest error display.
8. `src/pages/admin/AdminDashboard.tsx`: Hardcoded `'gemini-3.8-flash'` label and static telemetry numbers (`aiRequests: 1482`, `fileProcessingJobs: 214`).
